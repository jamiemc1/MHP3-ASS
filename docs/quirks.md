# Quirks of the original

Behaviour of `legacy/` that looks unintended but which the port reproduces
for parity. Each entry cites the original source and the golden fixture that
demonstrates it. Revisit once the differential-fuzz phase passes.

Parity covers search results and the files the original reads and writes.
How results are presented (display order, tie order, text formatting, find)
is the port's own design: entries marked **Changed by design** describe
presentation-only behaviour of the original that the port doesn't reproduce.
