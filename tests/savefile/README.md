# Local save data (not committed)

Save-import tests read a Monster Hunter Portable 3rd save file from this
folder: `MHP3RD.BIN`, copied from your own game save. Put reference output
captured from the original application next to it (for example the
`mycharms.txt` it writes after importing that save). The tests use these
files when present and skip otherwise.

Everything in this folder except this README is gitignored. Save files are
personal data and are never committed.
